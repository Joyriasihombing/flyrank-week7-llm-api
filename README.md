# FlyRank Capstone - Embeddable Widget Platform

## Overview

This project is a backend platform that allows users to create embeddable widgets for websites. Visitors can submit forms through these widgets, and submissions are validated, protected from spam, enriched with geolocation data, and stored securely.

## Tech Stack

- FastAPI
- SQLAlchemy
- SQLite
- JWT Authentication
- JavaScript Widget
- SlowAPI
- Docker (later)
